# Tajiro — Home

Лендинг главной страницы. Разобран из цельного `Tajiro-home.html` на исходники,
из которых собирается обратно — и в обычный сайт, и в один файл для отправки.

---

## Как это устроено

**`src/` — то, что правишь.** Одна секция страницы = один партиал + один файл
стилей (+ свой скрипт, если у секции есть поведение). Ищешь блок глазами на
странице — открываешь файл с тем же номером.

**`dist/` — то, что получается.** Целиком генерируется сборкой, руками туда
лезть не надо, в гит не коммитится.

```
tajiro/
├── src/
│   ├── index.html            каркас страницы: порядок секций и стилей
│   ├── partials/             разметка — по одному файлу на секцию
│   ├── css/                  стили — по одному файлу на секцию
│   ├── js/                   поведение — 4 независимых блока
│   └── assets/
│       ├── fonts/            4 шрифта (Almarai 400/700/800, Outfit 600)
│       └── img/              48 картинок вместо base64-простыней
├── tools/
│   └── build.mjs             вся сборка, без единой зависимости
└── dist/                     ← результат
    ├── index.html            сайт: подключённые css/js/картинки
    ├── css/  js/  assets/
    └── Tajiro-home.html      один файл со всем вшитым — для отправки
```

---

## Команды

Node уже стоит, ставить ничего не нужно — `npm install` не требуется.

Работать над страницей (собрать, поднять сервер, следить за правками):

```bash
npm run dev
```

Откроется на `http://localhost:4173`. Правишь файл в `src/` — сборка сама
пересобирает `dist/`, дальше обычный F5 в браузере.

Просто собрать оба варианта:

```bash
npm run build
```

После этого файл для отправки лежит в `dist/Tajiro-home.html` — тот же самый
цельный html, что был раньше, ничего не потерялось.

## Где что менять

| Что правишь | Куда идёшь |
|---|---|
| Текст, кнопки, ссылки в секции | `src/partials/NN-название.html` |
| Внешний вид секции | `src/css/NN-название.css` |
| Цвета, шрифты, отступы, кнопки — общее | `src/css/00-base.css` (токены в `:root`) |
| Шапка и мобильное меню | `src/css/00-header.css` + `src/js/header.js` |
| Появление блоков при прокрутке | `src/css/00-reveal.css` + `src/js/reveal.js` |
| Картинку заменить | положить файл поверх старого в `src/assets/img/` |
| Порядок секций на странице | `src/index.html` — переставить строки `<!--#include -->` |
| Title, description, og-теги | `src/partials/head.html` |

## Два правила, которые лучше не нарушать

**Порядок стилей в `src/index.html`.** `00-*` идут первыми: там токены, шапка и
общий механизм появления. Секции — дальше, в порядке страницы. Переставишь —
поедут перекрытия.

**`reveal.js` подключается последним.** Он сначала меряет, что уже в кадре, и
только потом взводит класс `.reveal-armed` на `<html>`. Пока класса нет, ни одно
правило из `00-reveal.css` не срабатывает. Поставишь скрипт выше — блоки успеют
мигнуть невидимыми.

## Мелочи, о которых стоит знать

- **Комментарии `<!--# ... -->`** в `src/index.html` — записки для себя, в сборку
  они не попадают. Обычные `<!-- ... -->` попадают.
- **Картинки лежат один раз, а на странице встречаются чаще.** Например,
  `icons/check-gold.svg` подставляется в 8 местах, `people/ai-influencer-omar.jpg`
  — в 4. В подключённой сборке браузер скачает такой файл один раз; в цельном
  файле он вшивается на каждое вхождение — отсюда его 3.8 МБ.
- **Цельный файл — это ровно та же страница.** Сборка проверена против исходного
  `Tajiro-home.html`: разметка совпадает символ в символ, стили совпадают,
  скрипты те же, набор картинок и шрифтов идентичен (48 уникальных ассетов).
- **Разобрать собранный файл обратно можно.** Маркеры `<!-- ===== 01-hero ===== -->`
  и `/* ===== 01-hero.css ===== */` сборка расставляет сама — именно по ним этот
  проект и был разобран из первой цельной версии.
